# Konvolucijske neuronske mreže

## Zadatak

1. Učitajte skup podataka **CIFAR-10** i prikažite uzorak od 20 slučajno odabranih slika iz skupa za treniranje zajedno s labelama.
2. Implementirajte **LeNet** konvolucijsku mrežu za klasifikaciju slika iz CIFAR-10 skupa.
3. Evaluirajte mrežu na skupu za testiranje i prikažite slučajan uzorak od 20 pogrešno klasificiranih primjera.

Predajte bilježnicu s rješenjem.
