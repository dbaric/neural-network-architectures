# Unaprijedne neuronske mreže za regresiju

## Zadatak

1. Modificirajte metodu `konstruiraj_model` tako da kao ulazne parametre prima brojeve neurona u skrivenim slojevima mreže.
2. K-strukom unakrsnom validacijom odaberite najbolju kombinaciju hiperparametara: broj neurona u skrivenim slojevima (barem dvije arhitekture) i `batch_size` iz {8, 16, 32, 64}.
3. Trenirajte mrežu "otpočetka" (50 epoha) na cijelom skupu za treniranje s najboljom kombinacijom.
4. Evaluirajte model na skupu za testiranje i usporedite s rezultatima s vježbi s fiksnim hiperparametrima.

Predajte bilježnicu s rješenjem.
